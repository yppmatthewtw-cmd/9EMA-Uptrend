# 9EMA-Uptrend Watchlist

全美上市普通股掃描：21EMA 向上、9EMA 在 21EMA 上方（或剛黃金交叉）、一底高於一底、股價回到 9EMA／21EMA 附近、形態接近上升三角（重心偏上）。

數據：Yahoo 日線（`.github/workflows/fetch_yahoo_eod.yml` 在 GitHub Actions runner 上抓取後 commit 到 `data/yahoo/`，研究容器本身連不到 Yahoo）。
股票池 `data/yahoo/tickers.txt` 承接 [10MA-watchlist](https://github.com/yppmatthewtw-cmd/10MA-watchlist)。
